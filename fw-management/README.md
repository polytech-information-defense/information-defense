# Подсистема управления (Management Subsystem) ПО МЭ

Данная папка содержит исходный код подсистемы управления программного обеспечения межсетевого экрана (ПО МЭ), разрабатываемого в рамках курсового проекта.

## 1. Назначение подсистемы
Подсистема управления предназначена для предоставления администратору безопасности удобного интерфейса для настройки, мониторинга и сопровождения межсетевого экрана. Она реализует требования спецификации **УПР (Управление)** и **ДСТ (Идентификация, аутентификация и разграничение доступа)**.

## 2. Решаемые задачи
Согласно спецификации, данная подсистема должна решать следующие задачи:
*   **Управление политикой доступа:** создание, удаление и модификация правил фильтрации, включая настройку параметров трансляции адресов (NAT).
*   **Разграничение прав:** поддержка двух ролей — «Чтение/Запись» (ЧЗ) и «Только чтение» (ТЧ).
*   **Управление конфигурациями:** сохранение, применение и сброс к заводским настройкам.
*   **Взаимодействие:** предоставление двух типов интерфейсов — командной строки (CLI) и веб-интерфейса (Web) с единым ядром логики.
*   **Мониторинг и управление:** управление контролем состояний, сетевыми интерфейсами, системными маршрутами и пользователями.

## 3. Что уже реализовано в рамках текущего этапа
На данный момент в ветке `management-subsystem` реализованы следующие компоненты:
*   **Контракт данных:** Создана JSON-схема (`config/config.schema.json`) и дефолтный конфигурационный файл (`config/config.json`) для хранения правил фильтрации.
*   **Ядро (Core):** Реализован модуль `core/rules.py`, содержащий бизнес-логику для CRUD-операций над правилами (добавление, изменение, удаление, перенумерация, переключение активности).
*   **Валидация (НДЖ-04):** В ядре реализована строгая проверка всех вводимых полей (IP-адреса, MAC-адреса, порты, протоколы, логика действий) согласно требованиям ФЛТ-04, ФЛТ-05, ФЛТ-07, ФЛТ-09.
*   **Тестирование:** Написаны модульные тесты (`tests/test_rules.py`) с использованием библиотеки `pytest`, покрывающие все поля валидатора и CRUD-операции (как успешные сценарии, так и обработку ошибок).
*   **CLI (Базовый):** Подготовлен каркас для командного интерфейса (`cli/main.py`), который будет использовать функции ядра.

## 5. Запуск CLI и тестирование

На данном этапе развития проекта подсистема управления изолирована от подсистемы фильтрации (которая разрабатывается отдельной командой). Поэтому полноценный запуск межсетевого экрана пока невозможен. Однако вы можете протестировать логику ядра и работу командного интерфейса (CLI).
